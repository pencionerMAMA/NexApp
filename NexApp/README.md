# Nex — островок для Windows

Чёрная капля сверху экрана, как Dynamic Island. Нажми на неё (или **Ctrl + Alt + N**) — и она раскроется.

## Что умеет
- **Музыка** — видит, что играет в Spotify, YouTube в браузере, Яндекс Музыке и любом плеере Windows: обложка, название, прогресс. Пауза / вперёд / назад.
- **Погода** — сама определяет город (или впиши свой в настройках), прогноз на 6 дней.
- **Wi‑Fi** — список сетей, подключение с паролем, отключение, вкл/выкл.
- **Bluetooth** — вкл/выкл, список сопряжённых устройств и их статус.
- **Не беспокоить** — скрывает уведомления всех программ Windows.
- **Громкость и яркость** (яркость — только на ноутбуках).
- **Буфер обмена** — история всего, что ты копировал, с закреплением.
- **Скриншот** — сохраняется в «Изображения/Nex» и сразу копируется.
- **Задачи и заметка**, **таймер** со звуком.
- **Система** — процессор, память, диск, батарея, время работы.
- **Чат с Nex** — твой друг, знает твоё имя, город и что ты сейчас слушаешь.
- Свой цвет, фон островка (чёрный / твои обои Windows / своя картинка), аватарка, вид «капля» или «плавающий».

## Мозг Nex (бесплатно)
Аватарка справа сверху → «Мозг Nex»:
- **Ollama** — `ollama pull qwen2.5:7b`
- **OpenRouter** — ключ на openrouter.ai/keys

## Если Wi‑Fi пишет «Windows не даёт искать сети»
Параметры → Конфиденциальность → Расположение → включи «Разрешить приложениям доступ к расположению» и «Разрешить классическим приложениям».

## Вход через Google (необязательно)
1. console.cloud.google.com → создай проект.
2. «API и сервисы» → «Экран согласия OAuth» → External → заполни название.
3. «Учётные данные» → «Создать» → «Идентификатор клиента OAuth» → тип **«Приложение для ПК»**.
4. Открой файл `%APPDATA%\nex\settings.json` и впиши:
   `"googleClientId": "…", "googleClientSecret": "…"`
5. Перезапусти Nex.

## Сборка
Залей папку в GitHub → вкладка Actions → скачай `Nex.exe`.

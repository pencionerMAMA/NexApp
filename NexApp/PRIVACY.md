# Политика конфиденциальности Nex

Последнее обновление: 21 ноября 2026

**Nex** — бесплатное приложение для Windows (островок на рабочем столе с помощником).

## Какие данные использует Nex
- **Профиль:** имя, дата рождения, почта, аватар, тема, город, язык — вводит сам пользователь.
- **Вход через Google:** имя, почта и фото аккаунта Google.
- **Google Drive (скрытая папка приложения, `drive.appdata`):** Nex хранит там только свой файл с профилем пользователя, чтобы восстановить его на другом компьютере. Nex не видит и не читает другие файлы на Google Drive.
- **Файлы на компьютере:** Nex индексирует названия папок и программ, чтобы находить и открывать их. Индекс хранится только на этом компьютере.
- **Чат с помощником:** сообщения отправляются в сервис ИИ (Groq), чтобы получить ответ.
- **Код подтверждения почты:** отправляется на указанный адрес через Gmail.

## Чего Nex не делает
- Не продаёт и не передаёт данные третьим лицам для рекламы.
- Не хранит данные пользователей на собственных серверах — у разработчика нет общей базы пользователей.

## Удаление данных
- Удалить локальные данные: папка `%APPDATA%\nex`.
- Удалить облачную копию: Google Drive → Настройки → Управление приложениями → Nex → «Удалить скрытые данные приложения».
- Отозвать доступ Google: https://myaccount.google.com/permissions

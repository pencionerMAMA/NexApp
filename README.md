## Что умеет

- **ИИ-помощник** — отвечает на вопросы, открывает программы, пишет сообщения по команде
- **Погода** — сам определяет город
- **Музыка** — видит, что играет в Spotify, и управляет плеером
- **Перевод** — выдели слово в любой программе и нажми `Ctrl + Alt + T`
- **Wi-Fi, Bluetooth, ночной свет, «Не беспокоить»** — в один клик
- **Любимые программы** — открываются по клику
- **Задачи, напоминания, буфер обмена**
- **Свои обои, цвета и аватар**
- **6 языков** — русский, українська, English, Deutsch, 中文, 日本語
- **Обновляется сам**

Островок живёт только на рабочем столе и не мешает в играх и программах.

## Установка

1. Скачай [`Nex.exe`](https://github.com/pencionerMAMA/NexApp/releases/latest/download/Nex.exe)
2. Запусти. Если Windows покажет синее окно — нажми **Подробнее → Выполнить в любом случае**
3. Введи почту, подтверди кодом и заполни профиль

## Приватность

Профиль и настройки хранятся только на твоём компьютере в `%APPDATA%\nex`.
Сообщения чата отправляются ИИ, чтобы получить ответ. Больше ничего никуда не уходит.

## Важно

Nex использует ИИ и **может ошибаться**. Проверяй важную информацию.

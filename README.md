## Features

- **AI assistant** — answers questions, opens apps, sends messages on command
- **Weather** — detects your city automatically
- **Music** — shows what's playing in Spotify and controls playback
- **Translate** — select a word in any app and press `Ctrl + Alt + T`
- **Wi-Fi, Bluetooth, Night light, Do Not Disturb** — one click
- **Favorite apps** — launch with a click
- **Tasks, reminders, clipboard history**
- **Custom wallpapers, colors and avatar**
- **6 languages** — English, Deutsch, Русский, Українська, 中文, 日本語
- **Auto-updates**

The island lives only on the desktop and stays out of the way in games and apps.

## Install

1. Download [`Nex.exe`](https://github.com/pencionerMAMA/NexApp/releases/latest/download/Nex.exe)
2. Run it. If Windows shows a blue SmartScreen window, click **More info → Run anyway**
3. Enter your email, confirm the code and set up your profile

## Privacy

Your profile and settings are stored only on your computer in `%APPDATA%\nex`.
Chat messages are sent to the AI to get a reply. Nothing else leaves your PC.

## Note

Nex uses AI and **can make mistakes**. Double-check important information.
